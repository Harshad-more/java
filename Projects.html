2. RateHub – Store Rating Platform

RateHub is a web-based store rating platform where users can submit ratings for stores. Store owners can view their average ratings, while administrators can manage users and stores.

Technologies Used:

  • React.js
  • Node.js
  • Express.js
  • MySQL
  • Sequelize
  • JWT Authentication

Key Features:

  • User Registration and Login
  • Store Rating System (1 to 5 Stars)
  • Admin Dashboard
  • Store Owner Dashboard
  • Rating Management
